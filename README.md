# my-skills

Personalized Claude Code skills focused on cost-effective planning and agentic coding.

The goal is to front-load thinking — plan before code, audit before merge — so that token spend goes toward decisions that matter rather than iterative trial-and-error.

## Skills

- **fire-plan** — disciplined agentic workflow: research → proposals → human approval → implementation
- **code-audit** — static audit of Python/C# source against coding standards
- **skills-audit** — quality audit of skills in this repo
- **search-docs** — look up documentation for any library or tool

## Install

```bash
uv run install.py
```
